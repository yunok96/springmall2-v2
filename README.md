## 프로젝트 개요

로그인, 회원가입, 상품 등록, 상품 조회 가능한 쇼핑몰 웹 애플리케이션입니다. 개인 프로젝트로 개발 진행했으며, 중간에 집중이 끊겨서 종료되었습니다.

## 주요 기능 (현재 개발/구상 중)

* **사용자 인증:**
    * [✅] 로그인
    * [✅] 회원가입
* **상품 관리 (판매자):**
    * [✅] 상품 등록 (Amazon S3, Presigned URL 활용)
    * [✅] 상품 수정
    * [✅] 상품 삭제
* **상품 조회 (구매자/판매자):**
    * [✅] 상품 목록 조회
    * [✅] 상품 상세 정보 조회

## 기술 스택

* **Backend:** Java 17, Spring Boot 3.4.4, Gradle(Groovy), JPA, Mysql
* **Frontend:** Thymeleaf, Bootstrap 5
* **External Service:** Amazon S3, Azure App Service, Azure Database
